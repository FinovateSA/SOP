what even is this

Claude, off the leash

The Claude you know answers questions. Claude Code does the work. Point it at a folder and it can read what's there, create and edit files, run commands, fix its own mistakes, and keep going until the job's done — all from a chat in your terminal.

Think of it as a very fast junior who happens to know every language, never gets bored, and asks before doing anything scary.

the honest bit

Do I need to be a developer?

No. You talk to it in plain English. It writes the code. Plenty of people who've never written a line use it to wrangle files, build little tools, and automate boring jobs. If you can describe what you want, you can drive it.

same brain, three doors

CLI, editor, or desktop?

It's the same Claude Code underneath — same abilities, same model. All that changes is where you sit and how much hand-holding you get.

TERMINAL · CLI

The raw one

Run claude in a terminal. Most flexible, and where the power lives — scripting, automation, running things headless. This is the playground for writing lekker scripts.

CODE EDITOR

The comfy one

The VS Code or JetBrains extension. Same engine, but you see edits as inline diffs and it knows the file you're looking at. Best if you live in an editor.

DESKTOP APP

The friendly one

Claude Code inside the desktop app — buttons instead of keystrokes, visual previews, gentle prompts. The softest landing (you're probably reading this in it).

So your hunch is right: start on a friendly surface, drop to the CLI when you want to automate and experiment.

get it running · ~5 min

From zero to first build

Install Node.js

Claude Code runs on Node. Grab the LTS button from nodejs.org and click through. (No Python needed.)

Install Claude Code

Open a terminal (on Windows: PowerShell) and run:

$ npm install -g @anthropic-ai/claude-code

Launch & sign in

Type claude and it opens your browser to log in with your normal Finovate Claude account.

$ claude

Point it at a folder & talk

Move into a folder (ideally an empty playground one), start Claude, and just say what you want.

$ cd ~/Desktop/playground && claude

a proper example · follow along

Guided build: your own start page

One real mini-project, start to finish, so you can see how a session actually flows. The whole trick: don't ask for everything at once — build it up, one line at a time.

> build me a personal start page — a big clock and a greeting that changes with the time of day
Creates index.html, writes the HTML, CSS and JavaScript, opens a live preview. You've got a ticking clock in about 20 seconds.
> nice. add a row of quick links to the sites I use most
Adds a link bar and asks which sites you want — you tell it, it fills them in.
> make it dark, with a slow animated gradient behind everything
Restyles the page and shows you the change before saving it.
> add a box with a random quote each load, then tell me how to set this as my browser homepage
Done — then walks you through the browser setting. You now open your own page every morning.

That's the entire game: describe → look → refine. Same loop whether you're building a toy or automating a real chore.

before you get carried away

The rules still apply

read this once

Claude Code runs on your actual machine and can read, write and run things. So: keep it to your own files and sandbox projects — not live client folders — and read what it proposes before you approve it. Same data-care rules as the rest of this guide. Treat it like power tools: brilliant, and worth respecting.
